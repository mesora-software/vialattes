# Documentação técnica — Vialattes

## Sobre a documentação

Esta documentação reúne os diagramas UML elaborados
durante a modelagem do Vialattes.

Os artefatos representam tanto funcionalidades do
protótipo atual quanto recursos previstos para
etapas posteriores do desenvolvimento.

## Diagramas UML

### 1. Diagramas de casos de uso
Visão geral das funcionalidades previstas para a plataforma.

### 2. Diagramas de atividades
Representação dos fluxos de execução das funcionalidades.

### 3. Diagramas de sequência
Descrição das interações entre os componentes do sistema.

### 4. Diagrama de classes
Representação da estrutura conceitual das entidades
e de seus relacionamentos.

## Estado do desenvolvimento

O protótipo funcional atual contempla a navegação
pelas principais interfaces e a missão "Posição",
do módulo de cinemática.

Os mecanismos de autenticação, persistência de dados
e serviços de backend integram o planejamento
de desenvolvimento futuro.
