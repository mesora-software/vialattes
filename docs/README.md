## 📖 Sobre a documentação

Esta documentação reúne os diagramas UML elaborados durante o processo de Engenharia de Software do Vialattes.

Os artefatos apresentam a estrutura funcional, os fluxos de execução, as interações entre componentes e a modelagem conceitual das entidades da aplicação.

A documentação contempla tanto funcionalidades presentes no protótipo quanto recursos planejados para etapas posteriores, servindo como referência para a evolução técnica da plataforma.

> **Importante:** os diagramas representam a modelagem do sistema e não necessariamente o estado atual de sua implementação. Funcionalidades relacionadas à autenticação, persistência de dados e serviços de backend fazem parte do planejamento de desenvolvimento futuro.

## 🚧 Estado do desenvolvimento

O Vialattes encontra-se em desenvolvimento incremental.

### ✅ Protótipo funcional

A versão atual concentra-se na implementação do frontend e contempla:

- Página inicial de apresentação da plataforma.
- Dashboard com módulos de aprendizagem e elementos visuais de gamificação.
- Navegação entre as principais interfaces.
- Missão interativa **Posição**, pertencente ao módulo de Cinemática.
- Controles de movimentação e sistema de mira.
- Interface de conclusão da missão.

### 📋 Funcionalidades planejadas

A modelagem UML também contempla recursos previstos para etapas posteriores:

- Autenticação e gerenciamento de usuários.
- Persistência de dados e acompanhamento do progresso.
- Implementação dos serviços de backend.
- Ampliação dos módulos e das missões de Física.
- Integração dos sistemas de recompensas e conquistas.

A implementação dessas funcionalidades será realizada progressivamente, conforme a evolução do projeto.

## 🎓 Contexto acadêmico

Os diagramas UML foram elaborados como parte das atividades de análise e projeto de software desenvolvidas no Trabalho de Conclusão de Curso em **Engenharia de Software**, no Centro Universitário Internacional UNINTER.

A documentação complementa o relatório acadêmico, permitindo consultar os artefatos de modelagem que fundamentaram as decisões de desenvolvimento do protótipo.

A disponibilização desses materiais tem como finalidade apresentar o processo técnico de concepção e estruturação do sistema.
